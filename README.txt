ENVIX - Dev Environment Setup Tool

This tool helps you set up a development environment quickly by installing programming languages, tools, and ready-to-use project setups.

What it does
Installs languages like Python, Node.js, Java
Installs tools like Git and VS Code
Sets up development presets (e.g., Web Dev, Backend)
Creates project folders with basic starter files
Checks your system and suggests fixes if something is missing
How to run
Download the .zip file
Extract it
Run the .exe file
Windows warning

When you run the app, Windows may show a WARNING like:

“Windows protected your PC”

This happens because the app is not digitally signed.  (It's not a Scam, so don't worry! it's normal and we're working on it - Thankyou!) 

To run it:
Click More info
Click Run anyway

Requirements
Windows 10/11
Internet connection
Admin rights (recommended for installations)
